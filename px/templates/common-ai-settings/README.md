## 🛠️ 문제 해결

### 일반적인 문제들

#### GitHub Copilot이 작동하지 않는 경우
1. 로그인 상태 확인: `Ctrl/Cmd + Shift + P` → "GitHub Copilot: Sign in"
2. 구독 상태 확인: GitHub 계정의 Copilot 구독 여부
3. 설정 확인: `github.copilot.enable` 값 검증

#### AI 제안이 느린 경우
1. 네트워크 연결 상태 확인
2. VSCode 재시작
3. 확장 프로그램 업데이트
4. 설정에서 성능 관련 옵션 조정

#### 설정이 적용되지 않는 경우
1. 워크스페이스 vs 사용자 설정 우선순위 확인
2. JSON 문법 오류 검사
3. VSCode 재시작 후 재확인
